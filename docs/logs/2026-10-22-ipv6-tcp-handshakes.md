# IPv6 TCP handshakes

Active and passive TCP handshakes now share the IP/TCP parser used by established flows. IPv6 addresses and extension headers survive parsing without IPv4 byte offsets. Invalid lengths, truncated headers, fragments, and mismatched Ethernet/IP families cannot register or complete a handshake. IPv6 peers without an MSS option use 1220; existing IPv4 passive and active defaults remain 536 and 1460. New SYN and SYN-ACK advertisements subtract the extra 20-byte IPv6 header from the configured link budget. Retransmissions retain the original options after an MTU change.

The dedicated xuan-work-mbp test Mac passed 148 splicetcp library tests with all features and no ignored tests, strict all-target/all-feature Clippy, workspace formatting, and default-feature splicetcp/arcbox-proxy compilation. Validation used Rust 1.96.0 and a fresh build directory. New tests use owned IPv6 loopback sockets and independent Ethernet/IPv6 fixtures with Hop-by-Hop headers. Coverage includes every truncated prefix, malformed headers, active ACK mismatch, both directions, MSS options and defaults, MTU bounds, saved retransmissions, sequence wraparound, output checksums, receive-window scaling, and exactly-once delivery of passive completion payload despite trailing padding and retransmission.

The first candidate failed Clippy because the peer-MSS default expression used `unwrap_or` instead of `unwrap_or_else`. The final candidate passes without a suppression. No handshake latency benchmark was run. The existing established ACK/download benchmark excludes connection setup and cannot establish handshake performance. This batch does not change the established packet loop.

The supplied Surge analysis describes address-family dispatch before transport dispatch. That static finding supports the shared-parser boundary; the socket tests provide the evidence for this implementation. Classifier activation, fragment delivery, and native IPv6 acceptance remain pending. Original App, NE, VPN, DNS, and interface state remained unchanged.
